# 💻 Hackintosh EFI 配置说明

本仓库提供适配该机型的黑苹果引导配置文件（EFI）。

## ⚠️ 重要提示（食用前必看）
* **已移除三码**：为了隐私和账号安全，文件中已移除 `MLB`、`SystemSerialNumber` 和 `SystemUUID`。
* **请自行添加**：在使用本 EFI 引导前，请务必使用工具（如 OpenCore Configurator）自行生成并填入三码，否则无法正常登录 Apple 账户。

---

| 硬件组件 | 驱动状态 | 详细说明 |

---

## ⚙️ 系统版本适配

* **macOS Monterey 及之后版本**：原生驱动对旧硬件（如 HD4600 和部分博通网卡）支持有限。
* **使用建议**：安装好系统后，需要搭配 **OCLP (OpenCore Legacy Patcher)** 进行打补丁，方可完美驱动核显与网卡。
